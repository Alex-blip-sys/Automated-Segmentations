# Automated-Segmentations
Ever wanted to make a massive pulmonary tree without all that extra hassle of individually fixing the outlets?  Relatable.  I'm trying to make it use a combination of the original vtp file and centerlines to figure it out.  Also for the record, github suggested naming this repository "cuddly-rotary-phone".  

The thing that this script actually needs circa NOW is the original .vtp file of the pulmonary tree (which you can happily acquire using the Total Segmentator extension from 3D slicer) and the centerlines of it (which you can happily acquire using the vmtk extension and asking for them politely or with a small amount of emphasis as needed). 
Given that you have both of these things and nothing bad happened in the process of acquiring them, you will now need to make a Trimmed version of your centerlines.  In absence of a barber, you can use the script titled "Something something script" which will clean up the centerlines and threshold them to a certain number of generations as defined by the number of branching points.  It returns it as a single vtp of shortened centerlines.
Take that funny fish and combine it with the script that should use it to chop off a bunch of the segments of the original pulmonary artery. Make sure you input the full 3D tree, the full 1D tree, and the trimmed 1D tree.
